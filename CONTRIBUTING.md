# Contributing

1. Create a topic branch from the default branch.
2. Install the dependencies with `python -m pip install -r requirements.txt`.
3. Run `python -m unittest discover -s tests` before opening a pull request.
4. Keep generated builds, user projects, and private assets out of commits.
5. Describe user-visible behavior and include a focused regression test for fixes.

By submitting a contribution, you agree that it may be distributed under the
MIT License used by this project.
