# FrameDeck Studio v12.0.0

The first public Windows release of FrameDeck Studio.

## Highlights

- Arrange image collections into PowerPoint, PDF, or page images.
- Confirmed Auto Layout can keep the generated page structure, while cancelling restores the previous version.
- Move images across pages and copy, cut, or paste into the selected page.
- Export editable PowerPoint crops while retaining the full source image.
- Use batch titles, spacing controls, bilingual Chinese/English UI, and five themes.
- Import HEIF/HEIC images through pillow-heif.

## Downloads

- `FrameDeck-Studio-v12.0.0-Windows-x64-Portable.exe`: no installation required.
- `FrameDeck-Studio-v12.0.0-Windows-x64-Setup.exe`: Chinese/English installer with shortcuts and uninstall support.
- `SHA256SUMS.txt`: SHA-256 checksums for both executables.

## Requirements

- Windows 10 or Windows 11, x64.
- Python is not required for the packaged applications.

## Signing notice

The v12.0.0 binaries are not digitally code-signed. Windows SmartScreen may
show an unknown-publisher warning. Verify the SHA-256 checksum before running
the downloaded file.
